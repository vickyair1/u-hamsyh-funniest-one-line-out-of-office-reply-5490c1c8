# Funniest One-Line Out-of-Office Reply

One line, 99 characters — the replacement is away too, so the person
emailing gets promoted to being in charge by default:

> I'm out of office. My replacement is also out of office, so congratulations — you're in charge now.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it
to stdout. Stdlib only, deterministic.
